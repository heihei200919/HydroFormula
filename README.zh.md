# 水利公式串联场景交互式计算平台

一个基于纯前端技术的 **水利工程公式教学与初步校核** 交互式计算工具，覆盖明渠、水闸、泵站、渡槽、隧洞、渗流等 **16类典型水利场景**。  
通过“场景选择 → 参数输入 → 一键计算 → 分步展示”的流程，帮助工程师、学生快速理解核心公式的应用，进行方案比选和初步复核。

> **⚠️ 重要声明**  
> 本工具旨在辅助教学、公式学习和初步估算，计算结果**不得替代专业设计软件、规范条文核查及工程师复核**。涉及坝坡稳定、渗流场、结构配筋、水锤等复杂问题，必须采用完整的设计方法和详细的边界条件。

---

## ✨ 功能特点

- **场景丰富**：内置 16 个常见水利计算场景，涵盖灌区渠道、水闸、泵站、渡槽、隧洞、土石坝、倒虹吸、生态流量、水环境、小流域洪水、水土保持、复式断面、沉沙条渠等。
- **公式串联**：每个场景按实际工程逻辑串联多个公式（如曼宁公式、水跃共轭、达西定律、USLE方程等），展示完整的计算链条。
- **交互式输入**：每个场景配有独立的参数面板，支持实时修改数值，单位明确。
- **分步计算结果**：点击“执行计算”后，以折叠面板形式展示：
  - 输入参数表
  - 依据的规范与公式
  - 参数校核（如流速范围、弗劳德数、安全系数等）
  - 核心计算步骤（含代入数值和中间结果）
  - 最终计算结果汇总表
  - 结果核对与汇总
  - 计算结论与适用范围
- **规范依据**：每个场景都标注了参考的国家或行业标准（如 SL 18、SL 265、GB 50288 等）。
- **纯前端**：无服务器依赖，无需网络，在浏览器中直接运行，数据安全。

## 🚀 快速开始

### 在线体验
将本仓库的 `index.html` 文件下载到本地，双击用浏览器打开即可使用（推荐 Chrome / Edge / Firefox）。

### 使用步骤
1. 从下拉列表中选择一个计算场景（如“灌区渠道断面设计与输水能力核算”）。
2. 在参数输入区域填写或修改各项参数（默认提供典型值）。
3. 点击 **“▶ 执行计算”** 按钮。
4. 等待计算完成，下方将展开七个折叠面板，依次查看输入、公式、校核、计算过程、结果、汇总和结论。
5. 可点击每个面板的标题栏展开/收起，便于对比不同参数下的结果。

## ⚠️ 注意事项

1. **专业限制**：本工具仅为教学与初步校核工具，**不可替代正式设计软件（如 ANSYS、MIDAS、MIKE 等）** 和规范要求的详细设计计算。
2. **参数范围**：默认参数仅为示例，实际工程需依据勘察、设计资料和规范取值。
3. **简化假设**：某些场景（如土石坝稳定、渗流）采用了简化模型（如平面滑动、平均坡降），结果仅用于趋势判断，不适用于实际安全鉴定。
4. **结果解释**：所有输出的结论均基于当前输入参数，修改参数后应重新计算并综合判断。
5. **浏览器兼容**：建议使用最新版 Chrome/Edge/Firefox，以确保所有特性正常工作。

## 📖 如何扩展或修改

- 新增场景：在 `SCENES` 对象中添加新的键值，参考已有结构定义场景信息、参数、公式和计算函数。
- 修改计算逻辑：在 `CALC` 对象中实现对应的计算函数，遵循 `(p) => { steps, checks, outputs, conclusion }` 格式。
- 调整界面样式：修改 CSS 变量（`:root`）可快速改变主题色和间距。
